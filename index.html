TS Correspondence Matrix — Complete Help Guide

📋 What is the TS Correspondence Matrix?

The TS Correspondence Matrix is the official correspondence tracking and management dashboard for the Andhra Pradesh Police — Technical Services (PCS&S) wing. It provides real-time tracking of all incoming and outgoing correspondence files.

🎯 Key Purpose

  • Track every correspondence file from receipt to completion
  • Monitor officer-wise workload distribution, Current Stage N/A & Concerned Officer N/A counts
  • Identify VIP/critical files & Further Follow-Up Required (Yes) tasks requiring immediate liaison
  • Track scheduled events like Video Conferences and Meetings
  • Generate consolidated printable & PNG Officer Abstract statements (1. Officer-Wise Workload → 2. Project-Wise Task Abstract → 3. Upcoming VCs → 4. VIP Inventory → 5. Follow-Up Depts)
  • Calculate SLA compliance and turnaround time metrics

🌐 How It Works

  • Data Source: All data lives in a Google Sheet — the single source of truth
  • Live Sync: The dashboard fetches live data from the Google Sheet every time you open it or click Refresh
  • No Login Required: Anyone with the dashboard link can view the data (read-only)
  • Update Data: To add/edit correspondence files, update the Google Sheet directly. Changes reflect on the dashboard immediately on refresh

📱 Quick Start for New Users

  1. Open the Dashboard — view the 5 clickable KPI capsules (Total, In-Progress, Completed + VIP, Stage N/A, and Follow-Up Required)
  2. On the Dashboard screen, use the top-right action bar (Screenshot, Officer Abstract, and FY 2026 Live Matrix Google Sheet link) — hidden automatically on other screens
  3. Inside Officer Abstract, click Generate Image or Print Officer Abstract to export or print the unified report
  4. Use the left sidebar modules to navigate between Dashboard, VIP Command (List View), Meetings & VCs, Officers, Projects, and All Records
  5. Click any correspondence ID (e.g., TS-COR-2026-0001) to view full 21-column file details in a popup

🗂️ Dashboard Tabs Explained

The dashboard has 6 main tabs accessible from the left sidebar. Each provides a different view of the same correspondence data.

1️⃣ Dashboard (Performance Report)

The home screen showing key performance indicators, charts, and executive actions (Screenshot, Officer Abstract, and FY 2026 Live Matrix appear exclusively on Dashboard).

  • 5 KPI Capsules: Total Files, In-Progress, Completed (+ VIP count), Stage N/A, and Follow-Up Required (Yes) — click any capsule to drill down into All Records
  • Charts & Analytics: Correspondence Status donut, Officer Workload stacked bar chart, Top Projects, Receipt Channel breakdown, and Pending Aging buckets
  • Executive Situation Report: Concise live summary with 1-click Copy Text, 15-Day SLA Compliance %, and Avg Turnaround Time

2️⃣ VIP Command (List View)

Displays all VIP correspondence in a structured full-width list/table view (matching All Records layout) based on the 4 VIP Pillars.

  • Filter by 4 Pillar radar tiles, status stage (Pending, In-Progress, Stage N/A, Completed), assigned officer, or search text
  • Click any row to open the full 21-column correspondence detail modal
  • VIP printable/PNG executive reporting is consolidated directly inside Officer Abstract on the Dashboard

3️⃣ Events (Meetings & VC)

Tracks scheduled Video Conferences (VC), Meetings, Seminars, Workshops, and key calendar milestones.

  • Shows files with Nature of Request = "Video Conference", "Meeting", "Workshop", "Seminar", etc.
  • 5 Timing & Status Filters: ⏳ Upcoming / Active, 🔥 Today & Tomorrow, ⏸️ Postponed (awaiting fresh schedule), 🚫 Cancelled, and 📁 All Events
  • Postponed events are highlighted with amber warning badges so officers know they are deferred
  • Useful for daily readiness checks, advance preparation, and executive reporting

4️⃣ Officers (Workload Distribution)

Officer-wise breakdown showing each officer's assigned files and their current stages.

  • Officers displayed in official hierarchy order (SP → Addl. SP → DSP → AAO → CI → SI → ASI)
  • Each officer card shows: Total files, In-Progress, Completed, Stage N/A counts
  • Click an officer card to see all files assigned to them
  • Tasks assigned to "ALL" officers appear separately as Common Tasks

5️⃣ Projects (PRJ Grouping)

Groups correspondence files by their assigned Project code (PRJ-001, PRJ-002, etc.).

  • Each project card shows: total files, In-Progress / Completed / N/A breakdown
  • Special projects like "PRJ-037 Miscellaneous" and "PRJ-038 ALL" are handled separately
  • Click a project to drill down into its individual files

6️⃣ All Records (Explorer)

Full data table with multi-criteria filtering and free-text search across every correspondence file.

  • Multi-filter by Officer (PRO-ID), Project (PRJ-ID), Priority / Follow-Up Required (Yes), and Stage Category
  • Use the search box for instant filtering across IDs, Subjects, Departments, Sources, Stages, and Remarks
  • Click any row to open the full 21-column correspondence details modal

🔄 Stage Categories — How Files Are Classified

Every correspondence file has a "Current Stage" field in the Google Sheet. The dashboard classifies all stages into 3 main categories for reporting, plus 1 exclusion category.

🔵 Category 1: In-Progress

Files that are currently being worked on at various stages of the processing pipeline. This includes files that are pending, being drafted, sent for approval, or even on hold.

All In-Progress Stages:

Draft Prepared Sent for Approval File Sent through eOffice File with IC File with DSP File with DIG File with IGP File with DGP Returned for Corrections Pending for Approval File with Govt. of AP Pending for DGP Approval Approved In Progress Work Completed - Pending for Approval File Dispatched Mail Sent Letter Sent Proforma Sent On Hold Overdue Postponed Pending

Note: If the stage field is blank or any unrecognized value, it also defaults to In-Progress.

🟢 Category 2: Completed

Files where all work is finished. Only the exact stage value "Completed" qualifies.

Completed

⚪ Category 3: Stage N/A (Not Updated)

Files where the concerned officer has not yet updated the current stage. The value in the sheet is explicitly set to "N/A".

N/A NA Not Available

⚠️ These files require the officer to update their current stage in the Google Sheet.

🚫 Excluded from Briefs: Closed / Excluded

These files are excluded from the Officer Abstract report, VIP reports, and active tracking. They appear in the data table but are NOT counted in KPIs or officer workload.

Correspondence Closed Cancelled Returned to concerned department

📋 Workload Calculation

  • Each officer's workload = Total reportable files assigned to them
  • Format: Total [Total = In-Prog / Completed / N/A]
  • "Closed / Excluded" files are not counted in any officer's workload
  • Files with Concerned Officer = "ALL" appear as Common Tasks visible to every officer
  • Unassigned files (no officer) are grouped under "Unassigned"

📝 How to Assign Officers

In the Google Sheet, update the "Concerned Officer" column with the officer's profile code and name (e.g., PRO-136 - T. Anoj Kumar (SI)). Set it to "ALL" if the task applies to all officers.

📋 Officer Abstract — Official Reports Summary

The Officer Abstract module (available on the Dashboard top bar) compiles the Executive Overview Strip and 5 official report tables in strict order for both PNG image export and A4 printing.

📑 Report Sections (Exact Order Only)

  1. OFFICER-WISE WORKLOAD SUMMARY: Official AP Police rank hierarchy workload table (Total, In-Progress, Completed, Current Stage N/A) plus explicit Concerned Officer N/A accountability row.
  2. PROJECT-WISE TASK ABSTRACT: Standardized Technical Project (PRJ-ID) task distribution across Total, In-Progress, Completed, and Current Stage N/A counts.
  3. UPCOMING VIDEO CONFERENCES: Scheduled Today & Upcoming Video Conferences with date, timing badge, agenda, concerned officer, stage, and VC link/remarks (excludes postponed, completed & cancelled).
  4. VIP & DIGNITARY FILES STATUS: Active 4-Pillars VIP file status showing File ID & Project, Dept & VIP Details (source department, dignitary designation & VIP pillar), Subject, Concerned Officer, and Current Stage (excludes Postponed, Follow-Up Required = Yes, Completed & Closed).
  5. PENDING INTER-DEPARTMENTAL FOLLOW-UP: Concise task-by-task status of all reportable tasks flagged Yes for department liaison, showing File ID & Project, Concerned Department / Wing, Subject, Concerned Officer, and Current Stage.

🖨️ Export Options

  • Generate Image: Captures a crisp white-background PNG containing the Executive Overview and Sections 1–5, copying to clipboard when supported.
  • Print Officer Abstract: Formats the exact same Executive Overview and Sections 1–5 for official A4 printing or PDF archival.
  • Exclusions: All "Correspondence Closed", "Cancelled", and "Returned to concerned department" records are automatically excluded.

⭐ VIP Classification — The 4 Pillars

Files are automatically classified as VIP based on 4 detection rules. A file needs to match at least one pillar to be flagged as VIP.

🏛️ Pillar 1: VIP Departments Source

File originates from a key apex authority department:

DGP Office High Court RTGS ITE&C MHA NCRB

📜 Pillar 2: Govt / DGP Executive Stage

File stage involves senior executive clearance such as File with DGP, File with Govt. of AP, or Pending for DGP Approval.

🚨 Pillar 3: Further Follow-Up Required = Yes

File is marked "Yes" in Further Follow-Up Required with Concerned Department. These tasks are also tracked in the Dashboard KPI capsule and dedicated Officer Abstract report table.

🎖️ Pillar 4: High Dignitaries Designation

Sender holds a high dignitary designation such as DGP, ADG, IGP, DIG, Principal Secretary, Chief Secretary, Secretary, or High Court Registrar.

📊 VIP Command List View & Report Rules

  • Unified List View: The VIP Command module displays all VIP files in a clean sortable table layout matching All Records — click any row for full 21-column history.
  • Officer Abstract VIP Report Scope: The 4. VIP & DIGNITARY FILES STATUS table inside Officer Abstract shows active VIP files with source Department & Dignitary details, Subject, Concerned Officer, and Current Stage — excluding Postponed, Follow-Up Required (Yes) tasks (tracked in Section 5), Completed & Closed.

⚠️ Important Rules for Data Entry

  • Always use the exact stage names listed in the Stage Categories section
  • Use "ALL" in Concerned Officer for tasks that apply to all officers
  • Date format should be consistent: DD-Mon-YYYY (e.g., 15-Jan-2026)
  • Do not delete rows — set stage to "Correspondence Closed" or "Cancelled" instead
  • The Correspondence ID must be unique for each row

🔧 Workflows & Tips

📝 Daily Workflow (Recommended)

  1. Morning: Open the dashboard → Check Overview KPIs → Note any new files
  2. Check VIP: Go to VIP tab → Review files requiring urgent attention
  3. Events Check: Go to Events tab → See today's/tomorrow's scheduled VCs/meetings
  4. Officer Abstract: Click "Officer Abstract" → Generate Image (to share PNG) or Print Officer Abstract
  5. Follow-up: Review officers with pending files → Request stage updates
  6. Update Sheet: As files progress, update the "Current Stage" column in Google Sheet
  7. End of Day: Refresh dashboard → Verify all updates reflected → Send closing brief if needed

🆕 How to Add a New Correspondence File

  1. Open the Google Sheet (click "FY 2026 Live Matrix" header link)
  2. Go to the last row and add a new entry
  3. Fill in: S.No, Correspondence ID (next sequence), Date of Receipt, Subject, Department, Concerned Officer, Nature of Request
  4. Set Current Stage to "Pending" or "In Progress"
  5. Set Priority to Normal, High, or Urgent
  6. Save — changes appear on dashboard within seconds on refresh

🔄 How to Update File Stage

  1. Open Google Sheet → Find the file by its Correspondence ID
  2. Update the "Current Stage" column to one of the official stage values
  3. Add remarks in "Decision/Remarks" column if needed
  4. Update "Last Follow-Up Date" to today's date
  5. If completed, set stage to "Completed"
  6. If no longer needed, set to "Correspondence Closed" or "Cancelled"

📤 Export CSV Report (Standardized Format)

Click "Export CSV Report" in the sidebar to download the active/filtered dataset as a UTF-8 Excel-ready CSV file featuring 26 standardized columns: all core Google Sheet fields plus Concerned Officer Assigned (Yes/No N/A), Status Category, VIP Classified & Pillars, VIP Inventory Eligible, Further Follow-Up Required, and TAT / Aging Metric.

📸 Dashboard-Only Workspace Actions & Executive Summary Copy

  • Click "Screenshot" to capture a full, high-resolution PNG snapshot of the active dashboard view and automatically copy it when supported.
  • Click "Copy Text" on the Executive Situation Report card header to copy the formal narrative brief ready to paste below your dashboard screenshot in WhatsApp or Email.
