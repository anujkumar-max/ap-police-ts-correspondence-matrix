TS Correspondence Matrix — Complete Help Guide

📋 What is the TS Correspondence Matrix?

The TS Correspondence Matrix is the official correspondence tracking and management dashboard for the Andhra Pradesh Police — Technical Services (PCS&S) wing. It provides real-time tracking of all incoming and outgoing correspondence files.

🎯 Key Purpose

  • Track every correspondence file from receipt to completion
  • Monitor officer-wise workload distribution and pending tasks
  • Identify VIP/critical files requiring immediate attention
  • Track scheduled events like Video Conferences and Meetings
  • Generate WhatsApp-ready briefings for quick officer communication
  • Calculate SLA compliance and turnaround time metrics

🌐 How It Works

  • Data Source: All data lives in a Google Sheet — the single source of truth
  • Live Sync: The dashboard fetches live data from the Google Sheet every time you open it or click Refresh
  • No Login Required: Anyone with the dashboard link can view the data (read-only)
  • Update Data: To add/edit correspondence files, update the Google Sheet directly. Changes reflect on the dashboard immediately on refresh

📱 Quick Start for New Users

  1. Open the dashboard — it loads with the Overview tab showing all KPIs
  2. Use the Officer Abstract button (orange, top-right) to open the Briefing Tool
  3. Click Copy WhatsApp Text to send daily briefs to officers
  4. Use the sidebar tabs (left) to navigate between VIP files, Events, Officers, Projects, and Explorer views
  5. Click any correspondence ID (e.g., TS-COR-2026-0001) to view full file details in a popup

🗂️ Dashboard Tabs Explained

The dashboard has 6 main tabs accessible from the left sidebar. Each provides a different view of the same correspondence data.

1️⃣ Overview (Performance Report)

The home screen showing all key performance indicators at a glance.

  • KPI Cards: Total files, In-Progress count, Completed count, SLA compliance %, Average turnaround time, VIP file count
  • Charts: Stage Distribution donut, Officer Workload bar chart, Project Progress bar chart, Monthly Trends
  • Executive Narrative: AI-generated situation summary in plain English
  • Correspondence Table: Full sortable, searchable table of all files with quick filters

2️⃣ VIP (High-Priority Files)

Shows only files classified as VIP — from apex departments, senior officers, or with urgent deadlines.

  • VIP files are auto-detected based on 4 classification pillars (see VIP section)
  • Shows VIP KPIs: total VIP, resolved, pending, require follow-up
  • Filterable by classification reason, status, and assigned officer

3️⃣ Events (Meetings & VC)

Tracks scheduled Video Conferences (VC), Meetings, and other time-bound events.

  • Shows only files with Nature of Request = "Video Conference" or "Meeting"
  • Calendar-style view with upcoming/past event classification
  • Useful for daily readiness checks and advance preparation

4️⃣ Officers (Workload Distribution)

Officer-wise breakdown showing each officer's assigned files and their current stages.

  • Officers displayed in official hierarchy order (SP → Addl. SP → DSP → AAO → CI → SI → ASI)
  • Each officer card shows: Total files, In-Progress, Completed, Stage N/A counts
  • Click an officer card to see all files assigned to them
  • Tasks assigned to "ALL" officers appear separately as Common Tasks

5️⃣ Projects (PRJ Grouping)

Groups correspondence files by their assigned Project code (PRJ-001, PRJ-002, etc.).

  • Each project card shows: total files, In-Progress / Completed / N/A breakdown
  • Special projects like "PRJ-037 Miscellaneous" and "PRJ-038 ALL" are handled separately
  • Click a project to drill down into its individual files

6️⃣ Explorer (Full Data Table)

Advanced table view with powerful filtering, sorting, and search capabilities.

  • Full-width sortable table with all columns visible
  • Multi-filter: by Stage, Officer, Project, Priority, Department, Date Range
  • Click any column header to sort ascending/descending
  • Use the search box for free-text search across all fields

🔄 Stage Categories — How Files Are Classified

Every correspondence file has a "Current Stage" field in the Google Sheet. The dashboard classifies all stages into 3 main categories for reporting, plus 1 exclusion category.

🔵 Category 1: In-Progress

Files that are currently being worked on at various stages of the processing pipeline. This includes files that are pending, being drafted, sent for approval, or even on hold.

All In-Progress Stages:

Draft Prepared Sent for Approval File Sent through eOffice File with IC File with DSP File with DIG File with IGP File with DGP Returned for Corrections Pending for Approval File with Govt. of AP Pending for DGP Approval Approved In Progress Work Completed - Pending for Approval File Dispatched Mail Sent Letter Sent Proforma Sent On Hold Overdue Pending

Note: If the stage field is blank or any unrecognized value, it also defaults to In-Progress.

🟢 Category 2: Completed

Files where all work is finished. Only the exact stage value "Completed" qualifies.

Completed

⚪ Category 3: Stage N/A (Not Updated)

Files where the concerned officer has not yet updated the current stage. The value in the sheet is explicitly set to "N/A".

N/A NA Not Available

⚠️ These files require the officer to update their current stage in the Google Sheet.

🚫 Excluded from Briefs: Closed / Excluded

These files are excluded from all WhatsApp briefs, VIP reports, and active tracking. They appear in the data table but are NOT counted in KPIs or officer workload.

Correspondence Closed Cancelled Returned to concerned department

📋 Workload Calculation

  • Each officer's workload = Total reportable files assigned to them
  • Format: Total [Total = In-Prog / Completed / N/A]
  • "Closed / Excluded" files are not counted in any officer's workload
  • Files with Concerned Officer = "ALL" appear as Common Tasks visible to every officer
  • Unassigned files (no officer) are grouped under "Unassigned"

📝 How to Assign Officers

In the Google Sheet, update the "Concerned Officer" column with the officer's profile code and name (e.g., PRO-136 - T. Anoj Kumar (SI)). Set it to "ALL" if the task applies to all officers.

💬 WhatsApp Briefs — Daily Officer Communication

The dashboard generates WhatsApp-ready text that can be copied and pasted directly into WhatsApp groups for daily officer status updates.

📍 How to Access WhatsApp Briefs

  1. Click the orange "Officer Abstract" button (top-right of dashboard)
  2. The Executive Briefing Tool modal opens with the Short Brief loaded by default
  3. Switch between brief formats using the tabs at the top of the modal
  4. Click "Copy WhatsApp Text" to copy the entire brief to clipboard
  5. Paste directly into your WhatsApp group

📄 Brief Formats Available

⚡ Short Numbers Brief (Default)

Quick numeric summary of officer-wise workload. Shows each officer's name, rank, total files, and [In-Prog / Completed / N/A] breakdown. Officers listed in rank hierarchy order. Includes "Kindly update the current stages" note for officers.

📅 Events Brief

Lists upcoming and recent Video Conferences, Meetings, and other scheduled events. Includes date, time, subject, and assigned officer for each event.

⭐ VIP Short Brief

Focused brief covering only VIP/critical files. Shows VIP KPIs (total, In-Progress, Completed) and lists each VIP file with its status, assigned officer, and reason for VIP classification.

💡 Tips for Effective Briefing

  • Send the Short Brief daily to keep officers updated on their workload
  • Send the VIP Brief when escalation or urgent follow-up is needed
  • Send the Events Brief before upcoming VCs/meetings for preparation
  • The briefs also include a Print Memo button for generating official printable memos
  • All briefs exclude "Closed / Excluded" files automatically

⭐ VIP Classification — The 4 Pillars

Files are automatically classified as VIP based on 4 detection rules. A file needs to match at least one pillar to be flagged as VIP.

🏛️ Pillar 1: Apex Department Source

File originates from a high-authority department or body such as:

DGP Office IGP Home Ministry Govt. of AP High Court NHRC / SHRC Legislature

🔴 Pillar 2: High Priority

File has an explicitly set Priority = "High" or "Urgent" in the Google Sheet.

⏰ Pillar 3: Deadline Approaching / Overdue

File has a due date that is within 7 days or already past and is not yet completed.

🏷️ Pillar 4: Senior Designation

The sender holds a senior designation such as DG, ADG, IG, DIG, SP, Collector, Secretary, or equivalent senior posts.

📊 VIP Dashboard Metrics

  • Total VIP: All files matching at least 1 pillar
  • VIP Resolved: VIP files with stage = "Completed"
  • VIP Pending: VIP files with In-Progress or Stage N/A
  • Require Follow-up: VIP files with pending status that have no recent activity

⚠️ Important Rules for Data Entry

  • Always use the exact stage names listed in the Stage Categories section
  • Use "ALL" in Concerned Officer for tasks that apply to all officers
  • Date format should be consistent: DD-Mon-YYYY (e.g., 15-Jan-2026)
  • Do not delete rows — set stage to "Correspondence Closed" or "Cancelled" instead
  • The Correspondence ID must be unique for each row

🔧 Workflows & Tips

📝 Daily Workflow (Recommended)

  1. Morning: Open the dashboard → Check Overview KPIs → Note any new files
  2. Check VIP: Go to VIP tab → Review files requiring urgent attention
  3. Events Check: Go to Events tab → See today's/tomorrow's scheduled VCs/meetings
  4. Send Brief: Click "Officer Abstract" → Copy Short Brief → Paste to WhatsApp group
  5. Follow-up: Review officers with pending files → Request stage updates
  6. Update Sheet: As files progress, update the "Current Stage" column in Google Sheet
  7. End of Day: Refresh dashboard → Verify all updates reflected → Send closing brief if needed

🆕 How to Add a New Correspondence File

  1. Open the Google Sheet (click "FY 2026 Live Matrix" header link)
  2. Go to the last row and add a new entry
  3. Fill in: S.No, Correspondence ID (next sequence), Date of Receipt, Subject, Department, Concerned Officer, Nature of Request
  4. Set Current Stage to "Pending" or "In Progress"
  5. Set Priority to Normal, High, or Urgent
  6. Save — changes appear on dashboard within seconds on refresh

🔄 How to Update File Stage

  1. Open Google Sheet → Find the file by its Correspondence ID
  2. Update the "Current Stage" column to one of the official stage values
  3. Add remarks in "Decision/Remarks" column if needed
  4. Update "Last Follow-Up Date" to today's date
  5. If completed, set stage to "Completed"
  6. If no longer needed, set to "Correspondence Closed" or "Cancelled"

📤 Export CSV Report

Click "Export CSV Report" in the sidebar to download the currently visible (filtered) data as a CSV file. This can be opened in Excel for custom analysis or printing.

🤖 AI Copilot

The floating "Executive AI Copilot" button (bottom-left) opens an AI-powered assistant that can answer questions about the correspondence data, help identify urgent files, and provide quick summaries. It is powered by Google Gemini and has real-time visibility into all dashboard data.

💡 Quick Tips

  • Use Ctrl+F on the Explorer tab for quick text search
  • Click any column header in tables to sort data
  • Use Light/Dark mode toggle (bottom-right sun icon) for your preference
  • The dashboard works on mobile — use the hamburger menu (☰) to access sidebar on small screens
  • Bookmark the dashboard URL for quick daily access
  • If data doesn't load, check if the Google Sheet sharing is set to "Anyone with the link can view"
